## 本次补充：围墙与镜头边界

- 四边增加连续石墙、青瓦压顶和垛柱，南侧接原有门楼。墙体与碰撞共用 `scenic_layout.gd::boundary_walls()`，按 16px 网格对齐；门柱另按实际占地阻挡，中央门洞和进镇道路保持畅通。城墙仍参与人物局部虚化。
- 删除世界视口上的 `ViewBoundary` 和旧边雾 shader；完整镇区在轻量、标准两档都关闭距离雾。东山岩脊不再随镜头位置消失。
- `camera_limits.gd` 将视口四角（含画外 2px 余量）投到低于所有地形的水平面，限制整个地面视锥，而非只限制跟随中心。调整窗口、俯角、FOV、旋转和 1×/2×/3× 时重新计算；必要时增大远裁剪距离，避免低俯角先切断地面。人物脚点处的缩放密度保持不变。
- 1×、低俯角或超宽窗口的视野会大于 1600×960 的玩法地图，因此墙外保留可重建的稀疏地形，只承担画面背景。远处网格逐渐变疏，最终边缘在玩法地图外 8192px；相机约束保留 32px 内缩余量，不扩大可走坐标、NPC 日程或服务器地图。
- 修复固定跟随中心在最外角、3× / 65° 时裁掉角色头部的问题：以全部动画帧的稳定包络限制人物在画面内，保留原生 HUD 余量，不通过缩小人物解决。

本轮截图和数据见下方“本轮边界验证”；此前的十五分钟数据单独保留，不能代替这次改动的测试。

## 画面复查后的修正

- 修好离线保存后草丛实例位置丢失的问题，草叶现已在实际 GPU 画面出现。
- 压低草叶和池水的受光亮度，避免发白和整片亮条纹。
- 处理长角色名撑宽状态块的问题，补足连接状态的文字对比度。
- 本次用围墙明确镇界，以视锥约束和稀疏背景地形藏住地块尽头，取消旧的世界坐标边雾。
- 删除多余的规则灌木长排，让建筑之间保留空地，并减少绘制开销。
- 收紧近景裁切，修好 1× 广角误切侧面建筑屋顶的问题。
- 38 个 Blender 环境模型通过独立重建一致性检查；旧 2D 契约和新地图的七处门前连通性均通过。

## 本轮边界验证

测试仍只用 Radeon 780M、Forward+ / Vulkan、轻量档和私有 gamescope / X11，测试用临时后端与临时存档，隐藏 NPC / 怪物。

- 逻辑契约通过：旧 2D 的 1,536,000 个可走点与像素画布不变，七栋建筑门前与南门连通；四边墙体阻挡有效。
- 镜头组合 **23,868 / 23,868 通过**：1100×720、1440×900、2560×1080、3840×2160；1×/2×/3×；30°/38°/65°俯角；30°/35°/40° FOV；环绕和默认方位；内侧与最外侧四角。检查视锥未越过背景地形尽头、远裁剪覆盖地面、角色全身在画面内和脚点缩放比例不变。3840×2160 在此仅为数学检查，不冒充实际 GPU 窗口测试。
- 实际 GPU 环境探针 **92 / 92 通过**：延续建筑、草丛、局部虚化、门洞净空和昼夜检查，新增围墙、两档无雾、九种边缘镜头。真实画面覆盖 1100×720、1440×900、2560×1080；抽查视口边缘像素没有落到背景色。
- 最终版真实键鼠检查 **23 / 23 通过**，连续运行 **180.02 秒**：WASD、实际点击视角滑条、中键环绕、滚轮 1×/2×/3×、虚化恢复、面板、商店真实结算、南门和四角，以及 3× / 65° 最外角的 1440×900 与 1100×720 缩窗行走。全程记录 **10,648 次实际绘制、1,269 个输入事件**，实际行走约 **14,961 逻辑像素**；抽样中的视锥越界、人物出画、雾启用次数均为 0。

## 如何运行

完整客户端（连接现有后端；AMD 轻量档）：

```bash
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/radeon_icd.json \
XIA_HD2D_QUALITY=light godot --path xia-ai-town \
  --rendering-method forward_plus --rendering-driver vulkan --gpu-index 0 \
  --display-driver x11 --disable-vsync --max-fps 60 res://scenes/hd2d/game.tscn
```

独立场景回归（临时后端和临时存档，测试中隐藏 NPC / 怪物）：

```bash
server/.venv/bin/python xia-ai-town/tools/hd2d_smoke.py \
  --background --game --scene-review --gpu-device amd --quality light --duration 900
```

布局与高度在 `scripts/hd2d/scenic_layout.gd`，场景界面在 `scripts/hd2d/scenic_hud.gd`。建筑通过 `tools/build_hd2d_environment.py` 重建，地形与固定场景通过 `tools/build_hd2d_scenes.gd` 重建。可编辑的固定场景仍在 `scenes/hd2d/town_scenery.tscn`。
