# M5 方案（待拍板）：让 NPC 不再机械

> 状态：**仅方案，未实施**。看完后请决定做哪几包、是否调整默认值；确认后再补入 `docs/DESIGN.md` §13，并拆成可执行清单。
>
> 目标：不推翻现有的确定性日程、服务器权威和零位置同步，只给 NPC 补上四样东西——**大家共同知道什么、今天想干什么、这场对话想干什么、眼前发生了什么**。
>
> 本版按用户意见新增 **改造包 W：世界公设与立场分化**，并把它放在最前面：要让 NPC 说话有指向性，先得给这张地图一个所有人都知道的背景，再让身份与记忆决定每个人怎么反应。

## 0. 一句话诊断

现在的 NPC 不笨，记忆、RAG、反思、关系摘要都已经够用，问题是它们**没有“当下”，也没有共同的“当下”**：

- **行动机械**：每天都是同一张时刻表，家 → 工作地 → 镇口 → 工作地 → 家，只有很小的踱步抖动；NPC 不选择、不偏离、不对任何事做出反应。八卦也只是后台写两条记忆，玩家看不见。
- **说话机械**：对话 prompt 里有性格、口癖、好感、记忆、最近几轮，但没有“这场对话我想达到什么”。所以 NPC 只能礼貌地回答玩家，答完就没了；所有 NPC 用的都是同一种“接话”姿势。
- **说话没有指向性**：小镇没有一个“所有人都知道的共同话题”。玩家问“后山那事”，七个 NPC 只能各自从性格里临时编，既没有共同事实可以对齐，也没有立场分歧可以玩。斯坦福小镇的对话有方向，是因为居民共享同一串正在发生的事，又各有私心。
- **缺最后一公里**：斯坦福小镇真正起作用的是「反思 → 形成意图 → 影响计划/对话」的闭环，而我们目前走到了“反思 → 多一条记忆”就停了。

## 1. 从斯坦福小镇借什么、不借什么

**值得借的：**

- 反思不只是总结，还要产出“我现在在意什么”，并影响接下来的行为；
- NPC 有私心、议程、情绪，不是一个有记忆的问答机器；
- NPC 能感知附近刚发生的事，并做出即时反应；
- 对话有目的：想打听、想炫耀、想劝人、想回避，而不是永远等玩家提问；
- **居民共享同一串正在发生的事，但每个人对它的立场不同**——共同事实负责让对话有落点，身份与记忆负责让回答有分歧。

**不借的：**

- 不换成 LLM 自由生成全天计划、自由决定坐标和路径——现在的确定性日程是优点，不是包袱；
- 不做“内容即状态”、tick 账目、25 人全并发调度那一套，本项目是单玩家、服务器权威、位置零同步，照搬只会增加复杂度；
- 不把附近所有事件都写进长期记忆，现在的“记忆控制噪声”原则继续保留；
- 不为了生动让 NPC 锁住玩家或强行结束对话；
- **不引入任务系统**：不做任务栏、目标追踪、强制流程。世界公设是背景与谈资，不是主线任务；是否把“取回神器”变成拜师硬门槛，见 §9 问题 2。

## 2. 改造包 W（前置）：世界公设与立场分化

### 2.1 为什么放最前

说话有指向性，靠的不是让模型更会接话，而是先让小镇有一件**所有人都知道的事**。玩家走进镇子，问任何一个人“后山那事”，都应该得到回答——但七个人给出的说法必须不一样。

**设计原则：世界公设是“所有人都知道的那件事”，不是“所有人都知道的全部细节”。** 公共事实负责让对话有落点；知识分层、身份与记忆负责让回答有分歧。

### 2.2 世界公设（建议稿）

**公开事实（全镇都知道，不需要检索、不进记忆流）：**

- 半月前，一伙山贼上了后山崖，占住旧寨；为首的是黑旋风，镇上货郎、猎户近来都不敢往那边走。
- 传闻黑旋风从外头劫来了一件**神器**（暂名“断岳刀”），就藏在后山崖的寨子里；没人亲眼见过，但人人都说得有鼻子有眼。
- 破庙里的疯乞丐张馒头，是镇上唯一“出过远门”的人。他的疯话里反复念着“山外有山”；镇上传说，只有取回神器的人，才配听他说一句真话，才谈得上了解外面的世界。
- 剑阳道馆、玄铁堂、烟雨小筑三派近来都盯着后山。镇上流传：神器现世之日，三派会重开山门，收一个关门弟子。
- 玩家（秦侠客）夹在这件事里：无门无派，想拜师，就绕不开后山。

**这四件事就是全镇的“共同话题”。** 后续的搭话、对话议程、每日心事、附近事件，都优先从这里长出来，而不是让 LLM 凭空发明。

### 2.3 每个人都知道，但每个人的说法不同

| NPC | 身份 / 利益 | 对“后山神器”的立场 | 说话落点 |
|---|---|---|---|
| 顾长风 | 剑阳派掌门，重门派清誉 | 认定神器该归剑阳，嘴上却不屑“外物乱心”；厌恶山贼，也不愿向张馒头低头 | 考校玩家有无资格上山；贬低另外两派；绝不承认自己在意 |
| 铁无双 | 玄铁堡堡主，豪爽嗜酒 | 想带人硬抢，把上山当成喝酒前的热身；觉得张馒头是装疯 | 拍胸脯要护着玩家；骂山贼；邀玩家同去 |
| 苏婉清 | 烟雨楼楼主，洞察多疑 | 怀疑“神器”是有人做的局，按兵不动，爱套别人的话 | 反问玩家听谁说的；半真半假地提醒；不说自己查到了什么 |
| 王大柱 | 铁匠铺主，消息贩子 | 不关心神器归谁，只关心消息能卖几个钱 | 兜售真假参半的寨子布防；先谈价；对神器本身支支吾吾 |
| 陈半松 | 药铺大夫，慈祥啰嗦 | 只担心上山的人送命，避谈宝物 | 念叨当年为宝物死的人；劝玩家多备药；一说到神器就转开话头 |
| 柳小蝶 | 客栈掌柜之女，爱看热闹 | 把这事当全镇最热闹的谈资，说法最夸张 | 抢着讲听来的“亲眼所见”；添油加醋；追问玩家何时上山 |
| 张馒头 | 疯乞丐 / 隐世高人 | 知道神器的真正来历和“外面的世界”，在等一个取回神器的人 | 用押韵疯话点人；不直接回答；玩家没拿到神器前不说破 |

**验收时的直观标准**：同一句“后山那神器到底怎么回事？”问这七个人，应该得到七种立场、信息量、语气都不同、但事实不互相矛盾的回答。

### 2.4 知识分层：谁知道什么

不能把整份设定塞给每个 NPC，否则七个人会变成同一个解说员，4B 还会顺着设定编。按“公开 / 传闻 / 机密”三层注入：

| 层级 | 内容 | 谁知道 |
|---|---|---|
| L0 公开 | 山贼占后山、黑旋风藏神器（传闻）、张馒头出过远门、三派盯着后山 | 全镇所有人 |
| L1 传闻 | 寨子布防、黑旋风弱点（真假参半）；“亲眼所见”的夸张版本 | 王大柱（布防）、柳小蝶（热闹） |
| L2 机密 | 神器真正来历、山外世界、取信张馒头的条件 | 只有张馒头 |
| L2 机密 | 本派打算；苏婉清额外知道另外两派的一些动静 | 三位掌门各自知道本派部分 |
| L2 机密 | 当年谁为宝物送命 | 陈半松 |

**硬规则：**

- prompt 只注入该 NPC 知道的那一层，不注入别人的秘密；
- 不知道就按性子岔开、装糊涂、反问，**不许编造新人物、新宝物、新门派**；
- 王大柱和柳小蝶可以说错、说夸张，但只能错在“传闻”层，不能新增 L2 事实；
- 张馒头在神器被取回前，永远不把真相说破；取回后也只说七分，留三分给后续版本。

### 2.5 怎么运作

**公设是静态数据，不由 LLM 生成。** 世界观、每个 NPC 的立场、知识分层全部写死在配置里，跟 `NPC_ROSTER` 放在一起；LLM 只负责在给定立场和知识范围内组织措辞。4B 没有能力稳定维护一套世界设定，也不该让它每次重新发明。

**注入方式（短、按话题挑）：**

- 对话/搭话时，先做一次关键词判断：玩家这句话是否提到“后山、山贼、黑旋风、神器、张馒头、拜师、武馆、山外”等公设词；
- 命中时，注入该 NPC 的“公开事实 + 个人立场 + 他知道的细节”，总长度控制在 120～200 字；
- 没命中时，只注入一句氛围提示（如“近日镇上都在议论后山的事”），避免每句话都硬提后山；
- prompt 里用第一人称见闻或“镇上都说”，不要写成设定条目；并明确要求“不要复述设定，只在相关或你想推进话题时提起”。

**世界状态（可选，轻量）：**

- 用 kv 记一个三阶段标记：`0` 山贼占山、神器只是传闻 → `1` 寨子被清 / 黑旋风伏诛 → `2` 玩家取回神器；
- 阶段变化后，注入的公开事实和 NPC 态度跟着变：从“听说”变成“真有其事”，从“劝你别去”变成“你真拿到了？”；
- 状态只影响措辞与议程，不改日程、坐标、好感结算；
- 若玩家在更新前已经杀过黑旋风，迁移时按 `mob_kills` 补成阶段 1，避免老存档卡在阶段 0。

**开场让玩家也知道：**

- 新开局/首次进镇时，客户端显示一段 4～5 行的“镇志”或开场白，把 L0 公开事实告诉玩家；
- 不做任务栏，不标目标点；玩家知道“大家都在议论什么”就够了；
- 调试接口 `GET /api/debug/npc/{id}` 增加该 NPC 的立场、知识层级和当前世界阶段，方便观察实验效果。

### 2.6 需要动的地方

- 新增 `server/app/game/world.py`（或并入现有静态数据模块）：公开事实、NPC 立场、知识分层、`brief_for(npc, topic, stage)` 纯函数；
- `dialogue.py` / `greet.py` 的 prompt 组装接入世界简报；`reflection.py`、`gossip.py` 可选接入（反思要能围绕“后山这事”想，八卦转述不能越过知识层）；
- 世界阶段读写走 kv，不进日程模块，不影响两端位置推算；
- 客户端只增加开场“镇志”展示，不新增轮询；对话/搭话仍走现有接口；
- 若做“取回神器”的物品与状态，优先复用后山崖黑旋风的击杀结算，不新增战斗流程。

### 2.7 成本与风险

- **零额外 LLM 调用**：公设、立场、知识层都是静态配置；世界简报只增加约 100～200 字 prompt，延迟影响可忽略；
- **4B 会把“知道”演成“什么都说”**：知识边界必须在代码里按 NPC 硬隔离，不能只靠 prompt 叮嘱；
- **4B 会编新设定**：prompt 明确“只依据给出的事实与你的见闻”，验收时专门测“问一个他不知道的细节”；
- **重复提后山会烦**：公设只在相关话题、议程需要或世界阶段变化时出现，不要求每句都提；
- **硬门槛风险**：若把“取回神器”做成拜师前置，会改动现有拜师规则（好感≥60、等级≥3）和“无主线任务”的边界。默认先做叙事层，见 §9 问题 2。

## 3. 改造包 A：心事与日程微偏离（解决“行动机械”）

### 玩家能看到什么

- 每个 NPC 每天有一件挂在心上的事，搭话或对话时会主动提起；
- 每天最多一次小的行程偏离：午间主动去找某个人、绕到某个铺面门口、提前一点回家等；
- 不同 NPC 的心事不同，玩家可以从对话里听出来“他最近在琢磨什么”。

### 怎么运作（大白话）

- 每天天亮时（或当天第一次被访问时），让 LLM 看这个 NPC 最近的反思、关系摘要、八卦和少量最近事件，**再给他一条与世界公设相关、符合本人立场的线索**，挑出 1 件“心事”，并写一句为什么是这件事；
- 心事当天不变，存下来；对话、搭话时把它拼进 prompt，让 NPC 有想推进的话题；
- 同时从一张**安全的偏离菜单**里选一个：去找某个 NPC、去某个公共点、某个时段换一个锚点。坐标和路线仍然由现有日程代码计算，LLM 只做选择题，不碰坐标；
- 模型失败、超时或输出不合理时，就当今天没有心事、没有偏离，行为完全保持现状。

### 需要动的地方

- 新增一小块“今日心事 / 微计划”状态，跟现有 NPC 状态一起下发给客户端；位置仍然不轮询；
- 日程推算增加一个“今日偏离”参数，服务器和 Godot 读取同一份数据，避免两端位置漂移；
- 调试接口展示心事和偏离，方便观察实验效果。

### 成本与风险

- 每个 NPC 每个游戏日 1 次低优先级调用，7 个 NPC 大约每 24 现实分钟 7 次，成本可以忽略；
- 偏离只能从预置安全点里选，默认每天最多一次，避免穿墙、卡住、显得乱走；
- 心事可能空泛：prompt 要求“优先落在世界公设下的个人立场，其次才从最近记忆里挑”，只写 1～2 句，失败直接回退；
- 没有世界公设时，心事很容易变成“今天想喝酒”这类无指向的随机念头；这就是 W 必须先做的原因。

## 4. 改造包 B：对话议程与主动性（解决“说话机械”）

### 玩家能看到什么

- NPC 会主动问“你最近在忙什么”“听说你上过后山”，会追问、会回避、会不高兴，而不是每句都等玩家提问；
- 不同 NPC 的开场、用词、关注点明显不同，不会每次都是“阁下所问”；
- 聊到对方不愿提的事，语气会变；聊得没意思，NPC 可能主动收尾。

### 议程从哪来

每场对话开始时，按 NPC 的立场权重，从预置议程池里抽 1 个（用 `npc_id + 游戏日 + 当日对话序号` 做种子，可复现，不额外调 LLM）：

- 打听玩家是否上过后山、见没见过黑旋风；
- 试探玩家对张馒头的看法，或玩家知不知道“山外”；
- 劝玩家别去 / 怂恿玩家去；
- 炫耀自己知道的那点传闻；
- 回避神器话题（心里有鬼或不想蹚浑水）；
- 为自家门派拉人（仅掌门）；
- 玩家完全没接话时，才回到通用议程（炫耀、诉苦、赶时间）。

再给一个“不愿提”的点，来自人设、最近的糗事，或知识分层外的事（例如陈半松不愿提当年为宝物送命的人）。议程、心事、关系摘要、当前情绪一起进 prompt；允许 NPC 反问、换话题、拒绝回答、主动结束。

### 怎么运作（大白话）

- 记录“最近聊过什么”，避免每场都用同一个开场；每个 NPC 给 2～3 句口癖示例，比只写“豪爽”“冷淡”更能定住说话风格；
- 加一个很轻的情绪：最近被送礼、切磋、冷落、八卦影响语气，持续一小段时间后恢复；**只改措辞，不改现有好感规则**；
- 议程优先来自世界公设，公共话题 + 个人立场 = 有指向性的对话。

### 需要动的地方

- 主要改对话与搭话的 prompt 组装，再加少量状态；**不增加 LLM 调用次数**；
- 对话结束逻辑允许 NPC 主动收尾，但玩家随时可以离开，不能被锁住；
- 情绪与议程要能在调试接口里看到，否则无法判断 NPC 为什么突然变脸。

### 成本与风险

- 成本几乎为零，都是同一次对话调用内完成；
- 主动性过强会烦人：每场最多主动 1～2 次，玩家不接就收，结束要礼貌；
- 情绪不能变成隐藏的好感惩罚，数值仍然只走现有规则；否则玩家会觉得“莫名其妙掉好感”；
- 议程如果不由规则约束，4B 会反复回到“打听/炫耀”两种，必须有池子和权重。

## 5. 改造包 C：眼前感知与即时反应（解决“NPC 像瞎子”）

### 玩家能看到什么

- 在旁边打架、赢了输了、送礼、被搭话，附近空闲 NPC 会冒一句反应；
- 短时间内再对话，NPC 能提起“方才那边动静不小”；
- 可选：午间聚集时两个 NPC 偶尔真的聊两句（气泡），而不是只在后台写八卦。

### 怎么运作（大白话）

- 服务器留一个很短的“最近发生的事”窗口，比如最近几分钟、同一地点或附近；对话或搭话时临时拼进 prompt，**不全部写进长期记忆**；
- 事件流里除了战斗、送礼、大额消费，也可以有公设相关事件：玩家清了寨子、取回神器、当众问起神器；但只有目击者知道，没看见的人仍然只能转述传闻；
- 对显著事件（战斗、送礼、大额消费、八卦）给附近空闲 NPC 一个低概率、带冷却的反应气泡；优先用模板，模板按 NPC 立场分化，只有少量高价值事件才调 LLM；
- NPC 之间的可见闲聊默认关闭；开启后也只在聚集时段、低频、低优先级，最多 2～4 句。

### 需要动的地方

- 需要一个轻量的事件流；先放内存、进程重启丢失也可以接受，不必马上入库；
- 对话和搭话读取这段短期上下文；
- 客户端增加反应气泡，以及可选的“双人对话”气泡显示。

### 成本与风险

- 事件太密会刷屏、prompt 膨胀；必须限地点、限时间、限频率；
- 反应气泡用模板兜底，LLM 只处理少量高价值事件；
- NPC 闲聊最容易“假”，也最费调用，建议默认关，先看 W+A+B 的效果再决定。

## 6. 建议实施顺序

| 阶段 | 内容 | 玩家感知 | 成本 | 建议 |
|---|---|---|---|---|
| 0 | W：世界公设 + 立场分化 + 知识分层 | 问谁都有的聊，回答不重样 | 极低（纯静态） | 先做 |
| 1 | B：对话议程 + 口癖示例 + 防重复 + 轻情绪 | 说话立刻不像客服 | 极低 | 紧接 |
| 2 | A：每日心事 + 一次安全微偏离 | 行动开始有自己的理由 | 低 | 再做 |
| 3 | C：附近事件感知 + 反应气泡 | 小镇开始“有反应” | 中 | 看效果 |
| 4 | C+：NPC 之间可见闲聊 | 最热闹，也最容易假 | 高 | 默认关，可选 |

理由：**W 是 B 的骨架**。没有 W，B 只能生成“想打听/想炫耀”的空议程，仍然没有共同话题；有了 W，议程、心事、反应气泡都能围绕“后山那件事”生长，而且彼此不重复。W 纯静态、零调用，先落地最稳。之后 B 最便宜，直接解决“说话机械”；A 解决“行动机械”，但要碰日程同步；C 最出效果，但要新增事件流和频率控制。四包可以分别上线、分别回退，不必一次做完。

## 7. 验收标准（建议）

**世界公设（W）：**

- 同一句“后山那神器到底怎么回事？”问七个 NPC，得到七种立场、信息量、语气不同、但事实不矛盾的回答；
- 张馒头以外的人不会说出只有张馒头知道的真相；王大柱、柳小蝶可以夸张，但不能凭空新增关键事实；
- 问一个 NPC 不知道的细节，他会岔开、装糊涂或反问，而不是编造；
- 新开局能看到一段“镇志/开场白”，玩家知道全镇在议论什么；
- 若做世界状态：击杀黑旋风或取回神器后，NPC 的说法和态度随之变化，且老存档能正确迁移。

**原有三包：**

- 连续观察两个游戏日：每个 NPC 至少一次主动提起自己的心事；玩家不主动问，也能听到新话题；
- 同一个 NPC 两场对话的开场和话题不重复；被冒犯时会变脸或收尾；
- 至少看到一次 NPC 因心事产生的小偏离，且没有卡墙、卡建筑；
- 玩家在 NPC 附近战斗后，NPC 短时间内能提起或做出反应；
- 对话延迟没有明显增加；模型失败或 Ollama 不可用时，所有功能回退到现状，游戏不卡（世界公设是静态的，回退后仍可提及）；
- 现有服务器冒烟与 Godot 冒烟保持全绿。

## 8. 默认开关与回退

- **W 默认开**：公设、立场、知识分层全部静态配置，不调 LLM；世界简报只加 prompt，不改任何玩法数值；
- **世界状态默认开但只读 kv**：阶段变化只改措辞与议程，不改日程、坐标、好感；若要做拜师硬门槛，单独加开关，默认关；
- **A/B/轻情绪默认开**；C 即时反应默认开但低频；NPC 可见闲聊默认关；
- 所有 LLM 生成失败都回退到现状：没有心事、固定礼貌回复、没有反应；世界公设仍然存在，因为它不依赖 LLM；
- 心事与微计划当天持久化，重启后不重新生成，保证可回放；
- 不改变现有日程锚点和路径，偏离只从白名单选；
- 不新增前台串行调用，后台调用继续走低优先级，不挤占玩家对话。

## 9. 需要你拍板的问题

1. 世界公设是否按 §2.2 的建议稿定？神器暂名“断岳刀”，是刀、剑还是别的物件？名字与形态一旦定下，会写进 `DESIGN.md` 和 NPC 台词。
2. “取回神器 → 得张馒头认可 → 三派重开山门收徒”是**镇上的说法**，还是**真正的拜师硬门槛**？建议先做前者（叙事层，不改现有拜师规则：好感≥60、等级≥3）；若要做硬门槛，需要同时修改 `DESIGN.md` §6.5 和“无主线任务”的边界，建议单独立项。
3. 知识分层是否照 §2.4 执行？尤其：张馒头独占核心真相、苏婉清比另两位掌门多知道一些，是否可以？
4. 世界状态要不要随玩家推进变化？建议至少做两档：清寨 / 取回神器；也可以先只做阶段 0，后续再开。
5. 行动上要不要允许 NPC 每天有一次小偏离？还是只改说话、完全不动日程？
6. NPC 可以主动结束对话吗？还是必须玩家说走才结束？
7. 要不要做 NPC 之间的可见闲聊？默认关是否可以接受？
8. 情绪只影响语气，还是也允许轻微影响好感？建议只影响语气。
9. 每天每个 NPC 多一次低优先级 LLM 调用（7 人约每 24 现实分钟 7 次），是否接受？

## 10. 一句话总结

**先给小镇一件所有人都知道的事，再给每个 NPC 一个只属于他的立场。** W 负责共同话题，B 负责个人议程，A 负责行动理由，C 负责眼前反应。建议顺序：W → B → A → C；W 纯静态、零成本，是其余三包的骨架。
